# אפליקציית „מחירון” לטלפון

אפליקציה אמיתית לאנדרואיד (React Native / Expo), עם אייקון משלה, כניסה שמורה, טביעת אצבע והתראות.
היא מתחברת **לאותו שרת, אותו מסד נתונים ואותם משתמשים** כמו אתר הניהול — כל שינוי באחד מופיע מיד בשני.
האתר במחשב נשאר כמו שהוא (תפריט צד, טבלאות).

## סנכרון מלא

האתר, האפליקציה והבוט עובדים על אותו מסד נתונים. בנוסף, כל מסך פתוח מחזיק „ערוץ חי” לשרת (`/api/live`):
כל שינוי — מחיר שעודכן, בקשה חדשה מהבוט, חיבור/ניתוק WhatsApp, יעד, משתמש, מחיר עומס — נשלח מיד לכל האתרים והטלפונים הפתוחים, והם מרעננים בדיוק את מה שהשתנה (תוך כשנייה).
כשהאפליקציה חוזרת מהרקע, או אחרי ניתוק אינטרנט, היא מרעננת הכול פעם אחת. הרענון התקופתי נשאר כגיבוי.

## התקנה (אנדרואיד, בלי חנות)

1. בטלפון, פותחים את דף הגרסאות של המאגר ב־GitHub (Releases) ומתחברים לחשבון GitHub — המאגר פרטי.
2. בגרסה העליונה („מחירון לאנדרואיד 1.0.N”) לוחצים על הקובץ `mechiron-1.0.N.apk` ← הורדה.
3. פותחים את הקובץ שהורד. בפעם הראשונה הטלפון יבקש לאפשר התקנה מהדפדפן („מקורות לא ידועים” / „התקנת אפליקציות לא מוכרות”) — מאשרים, חוזרים ולוחצים „התקנה”.
4. אם Google Play Protect מציג אזהרה („אפליקציה לא מוכרת”) — „פרטים נוספים” ← „התקנה בכל זאת”. זה קורה לכל אפליקציה שלא מגיעה מהחנות.
5. פותחים את „מחירון”, נכנסים עם קוד מ־WhatsApp או עם הקוד האישי. מהפעם הבאה — טביעת אצבע.

**עדכון:** מתקינים את ה־APK החדש מעל הקיים. הכניסה וההגדרות נשמרות.

## מה יש באפליקציה

| מסך | מה עושים בו |
|---|---|
| בית | מצב ה־WhatsApp של הבוט, בקשות מחיר, ממתינות לאישור, מסלולים, זמני עומס, פעילות אחרונה |
| מחירון | חיפוש מהיר (גם קיצורים כמו „בב ים”), סינון פעילים/מושהים/בעומס, הוספת מסלול |
| מסלול | 8 המחירים (צד אחד / הלוך ושוב), מחיר עומס פעיל, כינויים, השהיה, שליחה ב־WhatsApp והעתקה |
| עריכת מסלול | כל השדות כמו באתר, כולל „הדבקת הודעת מחיר מ־WhatsApp” |
| בקשות | מסלולים שהבוט לא מצא: אישור הערכה למחירון, עריכה, הוספה ידנית, סגירה |
| עומס | הפעלה/כיבוי מעקב, בחירת קבוצות, מחירים חיים עם זמן שנותר |
| עוד | חיבור WhatsApp (קוד צימוד / QR), יעדים, קיצורים, משתמשים והרשאות, מערכת ופעילות, התראות, טביעת אצבע, ערכת צבעים, יציאה |

ההרשאות זהות לאתר: מי שאין לו הרשאה רואה את המידע אבל בלי כפתורי העריכה.

## התראות לטלפון (הפעלה חד־פעמית)

השרת והאפליקציה כבר כוללים התראות על: בקשת מחיר חדשה, ניתוק WhatsApp (ושחזורו), ומחיר עומס חדש (כבוי כברירת מחדל).
באנדרואיד ההתראות עוברות דרך Firebase של Google (חינמי). עד שמחברים אותו, האפליקציה עובדת רגיל ומציינת שההתראות עוד לא הופעלו.

1. [console.firebase.google.com](https://console.firebase.google.com) ← Add project (למשל `mechiron`). אפשר לכבות את Google Analytics.
2. בפרויקט: Add app ← Android ← Package name: `app.pricebot.mobile` ← Register ← מורידים את `google-services.json`.
3. GitHub ← המאגר ← Settings ← Secrets and variables ← Actions ← New repository secret:
   שם `GOOGLE_SERVICES_JSON`, ערך: כל התוכן של `google-services.json`.
4. Firebase ← Project settings ← Service accounts ← Generate new private key ← מורידים קובץ JSON.
5. Railway ← השירות ← Variables: `FIREBASE_SERVICE_ACCOUNT` = כל התוכן של הקובץ מסעיף 4.
6. בונים APK חדש (Actions ← CI ← Run workflow) ומתקינים אותו מעל הקיים. ב„עוד ← התראות לטלפון” אפשר לבחור אילו התראות לקבל.

## iPhone

הקוד משותף ומוכן ל־iPhone. התקנה על iPhone דורשת חשבון Apple Developer (99$ לשנה) והפצה דרך TestFlight — בשלב הבא, כשתחליטו.

## פרטים טכניים

- הקוד: `artifacts/price-bot-mobile` (Expo SDK 54, expo-router, React Native 0.81, ארכיטקטורה חדשה).
- כתובת השרת מוגדרת ב־`app.json` ← `extra.apiUrl`. החלפת דומיין = לעדכן שם ולבנות APK חדש.
- כניסה: השרת מחזיר לאפליקציה אסימון כניסה (רק כשהיא מבקשת, בכותרת `X-Price-Bot-Client: mobile`), והאפליקציה שומרת אותו במאגר המאובטח של הטלפון. זו אותה רשומת כניסה כמו באתר — „ניתוק מכל המכשירים” ויציאה מבטלים גם אותה.
- התראות: טבלה `price_bot_push_devices`, נקודות `POST /api/push/devices` ו־`POST /api/push/devices/remove`, שליחה דרך FCM (או Expo Push).
- חתימה: `credentials/android.keystore` (סיסמה ב־CI). אסור להחליף — אחרת עדכון ידרוש הסרה והתקנה מחדש.
- בכל בניית APK: האפליקציה מותקנת ונפתחת באמולטור אנדרואיד; אם היא קורסת או לא מציגה את מסך הכניסה, הגרסה לא מתפרסמת.
